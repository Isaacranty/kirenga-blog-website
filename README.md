# Kirenga Blog Website

Static website files (HTML/CSS/JS).

## Overview
This repo contains the built/static files for the Kirenga blog website. It's primarily HTML with a bit of JavaScript.

## Run locally
- Open `index.html` in your browser, or serve the directory:

  python -m http.server 5173

or

  npm install -g serve
  serve .

## Notes
If this is a production output, keep the source repo for edits and treat this as the published artifact.
